# mrkoffi — Portfolio

Portfolio de **Koffi N'gouan Emmanuel** — développeur web & mobile, spécialisé bases de données & Big Data. Basé à Bouaké, Côte d'Ivoire.

Construit avec [Next.js](https://nextjs.org/) (App Router) + React.

## Démarrer

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
